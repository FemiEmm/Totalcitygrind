# Starting homes and phone update

New games ask for a player name and one of 20 empty single rooms, A1-A4 through E1-E4. Each uses its matching parking space. Rent uses the existing weekly amount of 20,000 naira, charged once at setup from the existing 50,000 starting cash; the next rent is day 8. The selected room, player name and rent schedule persist in saves and travel. Existing saves keep their current home and do not get charged a new setup payment. Availability is local to a fresh game; shared multiplayer occupancy requires server integration.

The starter rental remains the internal rental tenure; starterHomeId identifies its actual room/parking location. Sleeping and job/vehicle switching use that selected space. Ownership upgrades continue using the existing property IDs.

The adviser subscription, cancellation and renewal controls live in Messages > Stock Adviser. Stocks contains company trading and performance. Family chats are consolidated into Family group chat, including school fees, later requests, payment controls and thanks. Old contact IDs are mapped into the group to preserve saved requests and notifications. New-game names personalize messages; older saves without names use Driver.

Single-room rows bypass concrete pedestrian margins. Their entire footprint uses the dry mud base. Traffic Danfos use the player's sprite render scale and crop, including existing saved vehicles, on both maps.

Source reviewed only; no tests, builds or browser sessions run as requested.
